# SAII-nivelaci-n-Laprida

IMPLEMENTACION 1
Este trabajo se trata de crear una pagina web simple con intencion de repaso y practiaca de conceptos basicos.
En la version1, se trata de un archivo html trabajado solo con javascript y css.
El objetivo es el de permitir escribir texto en un input y al presionar ENTER el texto se desplegara en un alert, 
ademas de un boton que dejara cambiar los colores de la pagina.
-----------------------------------------------------------------------------------------------------------------------
Para ejecutar esta pagina puedes arrastrar el archivo a tu navegador o hacer doble click al archivo html.

El funcionamiento de esta pagina se base en el uso los eventos en Javascript, tomando el id y escuchando los evento que ocurren en el imput del texto y al boton para cambiar los colores.
-----------------------------------------------------------------------------------------------------------------------
IMPLEMENTACION 2
En este caso, se levantara la pagina usando un servidor usando node.js y express.
Para ejecutar este servidor, se debe colarse en la carpeta "version", abrir el terminal para descargar las dependencias con npm i, 
ejecutar el comando npm run dev, una vez de el mensaje de confirmacion, se puede colocar en la barra de navegacion "http://localhost:3000"
para acceder a la pagina.
